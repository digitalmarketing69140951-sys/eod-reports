# 4. The “Why” Analysis

### What worked

The day's workflow created a direct connection between performance diagnosis and implementation:

**Weekly performance data → PMax asset review → SEMrush keyword research → optimisation prompt → priority PDP**

The process also maintained separation between:

* Campaign-level performance evidence
* Asset-level evidence
* Organic keyword research
* Product/PDP optimisation

### What required caution

THEE_MYSTERY's **34.60% ROAS** remains substantially below the **250% target**, so PDP optimisation alone should not be treated as a guaranteed solution.

Similarly, THEE_GEMS at **158.97% ROAS** remains below target despite being the stronger campaign.

The PMax asset group had an **Excellent** strength rating, so asset optimisation was appropriately focused on relevance and messaging rather than assuming the asset group was fundamentally unhealthy.

The priority PDP had only **1 click and £1.09 spend**, meaning the optimisation currently represents a reasonable improvement hypothesis rather than a statistically validated conversion intervention.

### Main learning

Performance optimisation should continue to distinguish between **evidence of a problem** and **a hypothesis about its cause**. Today's changes improve relevance and optimisation quality, but post-change performance data is required before attributing ROAS improvement to the interventions.
