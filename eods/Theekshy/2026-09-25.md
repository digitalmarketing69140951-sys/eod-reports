# 4. The "Why" Analysis

### Performance work

The weekly analysis was appropriate for the final monitoring phase because it established the current MYSTERY/GEMS performance baseline without introducing unnecessary campaign changes. The main measurable concern was the difference between MYSTERY's **51.17% ROAS** and GEMS's **111.15% ROAS** during the review period.

The MYSTERY campaign was also **Limited by budget**, while GEMS was **Eligible with no serving issues**. These are separate diagnostic signals and were documented without assuming that budget status alone explains the ROAS difference.

### IO documentation

The IO work improved handover traceability by distinguishing **completed** requirements from items still awaiting stakeholder confirmation. In particular, the Merchant API migration was not prematurely marked as approved.

### PDP optimisation

The selected product had **42 impressions but zero clicks**, so the available evidence did not establish a conversion-performance problem caused by the PDP itself. The actionable issue identified was inconsistent/non-clean product naming between Shopify and GMC.

The title was therefore standardised while avoiding unnecessary image or description changes. Post-change performance should be evaluated through subsequent click, engagement, add-to-cart, conversion and feed-synchronisation signals.
