# E. Diagnostic Reflection — Mandatory

### What was tried

* Reviewed MYSTERY/GEMS performance before execution.
* Revalidated the 15-product waste-spend list.
* Protected products showing conversion activity.
* Excluded the remaining validated non-performing products.
* Conducted an evidence-led PDP review using Ads, Clarity and GMC/Shopify information.
* Updated PDP title, description and visual assets.

### What worked

* The final exclusion screening prevented automatic suppression of four products that had generated conversion activity.
* The performance-first sequence allowed campaign-level decisions to be separated from product-level waste-spend actions.
* The PDP optimisation was completed within the allocated **45-minute** window, using **40 minutes**.

### What failed / limitations

* The original 15-product waste list could not be treated as a permanently fixed exclusion set because subsequent evidence showed conversion activity for four products.
* PDP evidence was limited by the small traffic sample: **3 clicks**, **£0.77 spend**, and **1 targeted Clarity session**.
* Post-optimisation performance cannot yet be measured.

### Where time was saved

* Daily performance analysis: **35 vs 40 min**
* Exclusion implementation: **35 vs 40 min**
* PDP optimisation: **40 vs 45 min**
* **Total: 110 vs 125 min**, saving **15 minutes**.

### Lesson learned

Waste-spend exclusions should be **revalidated immediately before implementation** where campaign data can change between initial identification and execution. Conversion-active products should not be excluded solely because they appeared in an earlier waste-spend list.
